## 人工复核发现

以下比较只针对仓库固定资料，不判断当前法律状态。不得把这些例题的回答直接用于真实移民或税务决策。

| 题号 | 观察到的问题 | 后续处理 |
|---|---|---|
| 3 | 问入境时间，却回答签证签发时间；原文存在不同动作对应的不同数字 | 模型未正确选取问题所问的事实，保留为回归用例 |
| 4 | 答案给出数值，但引用的具体片段没有覆盖 C 标注的核心依据 | 审查逐条引用是否真正支持回答 |
| 5 | eCFR 快照和另一政府页面中的期限不同；回答只选其中一个，未提示冲突 | C 核对资料版本和适用范围；A 的提示词不是可靠的冲突检测器 |
| 12 | 没有检索到标注的校内工作段落；回答承认资料不足 | 检索覆盖问题交 C 复核；拒绝猜测比错误肯定更可取 |
| 16 | 不同来源的 OPT 申请截止时间不同，回答没有说明差异 | 与 C 一起检查版本、日期与来源一致性 |
| 23 | 回答把原文的时间关系改写成了不受支持的起止范围 | 保留为生成事实性回归用例 |
| 27 | 未检索到标注的 Form 8843 依据，回答未能给出表格名 | 检索覆盖问题交 C 复核 |

另外，第 11 题包含未被询问的校外工作信息，说明简洁性和类别区分仍有改进空间。未对其余答案给出正式“全部正确”的评分。

两种临时提示词调整没有稳定修复这些问题，未替换已验证的生产提示。未修改 C 的原始资料、问题集、标注或基线来提高分数。当前完成的是本地功能和有限案例验证，**不是可直接提供法律建议的成熟产品**。

## 复现

从仓库根目录、已配置本地服务和自己的授权 key 的环境运行：

```sh
python -m scripts.evaluate_a
python -m scripts.trace_embedding
```

第一条调用真实 embedding 和本地 Llama；第二条额外调用一次 embedding，保存真实查询向量的前 8 个坐标、1536 维信息、L2 范数、前四个命中块和余弦相似度。输出不包含密钥。
